# Input steps: behavior sources

Records the verdict for each rule that `2026-10-19-input-steps-design.md` marks **(source)**. A rule is
`confirmed` when Blizzard's Lua shows it; the source column then gives `path:line` relative to
`mirror/gethe/<branch>/` under the testkit home (fetched by `tools/fetch.sh`). A rule is `assumed` when no Lua shows
it; the source column then names the warcraft.wiki.gg page that supports it, or says "no source". Every `assumed`
rule has a test whose name ends in `_assumed`. A source that contradicts the spec stops the work until the user
approves a spec change.

## Phase 3

Wiki pages are on warcraft.wiki.gg, read 2026-10-20. Blizzard paths are relative to `mirror/gethe/<branch>/`. Two
groups of `UIDropDownMenu.lua`: Mainline (`live`, `forever`; `Interface/AddOns/Blizzard_SharedXML/Mainline/`, same
lines up to 1281, `forever` adds a `SmartNavigation` call there) and Classic (`classic`, `classic_era`,
`classic_anniversary`; `.../Classic/`, same lines, `classic_anniversary` differs by line endings only). The mirror holds
no `.xml`, so `UIDropDownMenu.xml` (the `UIDropDownListTemplate` and `DropDownList1..` definitions) cannot be read.
Where the source shows behavior other than the spec's text, the row records the source; the spec now follows the
source (S4, S5, S7, S8; decided 2026-10-20 under the user's delegation, logged in the plan's Phase 3 Handoff).
